## Deployment
This is a dependency-free static site intended for GitHub Pages from `main` and `/ (root)`. Keep the `docs/` and `assets/` paths unchanged so document downloads and brand provenance remain intact.

## Visual system
The candidate vision uses a dependency-free WebGL2 capability phase-lock field on desktop and a designed semantic fallback on touch and narrow-screen devices. The simulation is one-shot, settles into a stable state, supports deliberate replay, and resolves immediately under reduced motion.

## Regression check
Run `node qa/capability-transformer.contract.mjs` to verify that the superseded flat SVG is absent, WebGL2 and mobile fallback paths exist, reduced-motion and one-shot settlement are preserved, and the corrected visual stylesheet remains in the publication manifest.
